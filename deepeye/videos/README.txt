DeepEye Website - Video Files
==============================

Please place your MP4 video files in this folder with the following filenames:

  overview_demo.mp4     - Full product demo (~2 min), shown on "Full Demonstration" page
  output_report.mp4     - Report generation demo, shown on "Output: Report" page
  output_dashboard.mp4  - Dashboard interaction demo, shown on "Output: Dashboard" page
  output_video.mp4      - Auto-generated data video demo, shown on "Output: Video" page

Notes:
- All files must be in MP4 format (H.264 recommended for best browser compatibility)
- Videos will autoplay muted when the page scrolls into view
- Recommended resolution: 1920x1080 (16:9)
